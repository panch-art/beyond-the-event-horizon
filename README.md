# PANCHAMI | Beyond the Event Horizon 🌌

## Project Overview

Beyond the Event Horizon is my personal portfolio website, designed around the concept of cosmic exploration, NASA Mission Control, and the Quantum Realm.

The website represents my journey as a computer science student through an immersive space-inspired experience. It showcases my technical skills, projects, achievements, and contact information through a futuristic interface.

## Tech Stack

- **React.js** – Building reusable and interactive UI components.
- **JavaScript** – Implementing website functionality and interactions.
- **HTML5** – Structuring the website.
- **CSS3** – Styling, animations, transitions, and responsive layouts.
- **Vite** – Development environment and production build tool.
- **Git & GitHub** – Version control and source code hosting.
- **Netlify** – Website deployment and hosting.

## Key Features

1. **The Event Horizon – Home:** A cinematic black-hole-inspired landing page with a cosmic atmosphere and introduction.
2. **The Origin – About:** An introduction to my background and journey.
3. **The Quantum Realm – Skills:** A constellation-inspired presentation of my technical skills.
4. **The Discoveries – Projects:** Project showcases presented as futuristic research dossiers.
5. **The Trajectory – Achievements:** A timeline highlighting milestones and accomplishments.
6. **Beyond the Known – Contact:** A space-inspired contact section with ways to connect.

## Projects Featured

- **Musical Delight:** An interactive audio-visual web application.
- **Sepsis Guardian:** A healthcare analytics platform focused on early sepsis detection and patient risk.
- **Obstacle Avoiding Robot:** An autonomous robot designed to detect and avoid obstacles.
- **JobSuite:** A recruitment platform focused on connecting candidates with opportunities.

## Design Concept

The portfolio combines three themes:

- **Beyond the Event Horizon:** Cosmic exploration and the unknown.
- **NASA Mission Control:** Futuristic scientific interfaces and research-inspired layouts.
- **Quantum Realm:** Glowing elements, interconnected skill nodes, and a sense of exploration.

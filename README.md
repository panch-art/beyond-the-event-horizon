## 🚀 Project Overview

**Beyond the Event Horizon** is a personal portfolio website designed around the mysteries of space, cosmic exploration and the idea of discovering the unknown.

Inspired by NASA Mission Control, black holes and the Quantum Realm, this portfolio presents my academic journey, technical skills, projects and achievements through an immersive, futuristic experience.

Rather than following a conventional portfolio layout, I wanted to create a digital space that feels like an exploration mission, where every section reveals another part of my journey.

## 🪐 Concept & Visual Identity

The design combines deep-space backgrounds, shades of violet, electric blue and cyan, glowing visual elements and futuristic typography.

The experience begins with a cinematic mission-introduction sequence featuring an animated black hole, glowing accretion rings, system initialization progress and a smooth transition into the main portfolio.

The introduction plays automatically when the website is opened in a new browser session.

## 🌠 Key Features

- **Cinematic Mission Intro:** Animated black hole, accretion rings, system initialization progress and automatic transition into the homepage.
- **Galaxy-Inspired Cursor:** A custom cursor that complements the space-exploration theme.
- **Animated Cosmic Background:** Shooting stars, glowing elements and atmospheric space effects.
- **Interactive Skills Section:** Quantum-inspired nodes and visually organized skill categories.
- **Research-Inspired Project Cards:** Futuristic cards presenting projects and their technical details.
- **Orbital Achievement Timeline:** An animated timeline representing academic and personal milestones.
- **Wormhole-Inspired Contact Section:** A space-themed interface for connecting.
- **Smooth Transitions:** Animated page transitions and navigation effects.
- **Responsive Layout:** Designed to work across desktop and mobile screens.

## 🛠️ Running the Project Locally

**Prerequisites:**
- Node.js
- npm
- A code editor such as Visual Studio Code

**Steps:**

1. Clone the repository:

   ```bash
   git clone https://github.com/panch-art/beyond-the-event-horizon.git
   ```

2. Navigate into the project folder:

   ```bash
   cd beyond-the-event-horizon
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

**To generate a production build:**

```bash
npm run build
```
